# Keyboard Shortcuts

## Global (work even when unfocused)

| Shortcut | Action |
|---|---|
| `Ctrl+Alt+V` | Push-to-talk (hold to record) |
| `Ctrl+Alt+A` | Show/hide window |

## Navigation

| Shortcut | Action |
|---|---|
| `Ctrl+1–7` | Switch views (Chat, Providers, Memory, Security, Modes, Settings, Web) |

## Chat

| Shortcut | Action |
|---|---|
| `Enter` | Send message |
| `Shift+Enter` | New line |
| `Ctrl+N` | New conversation |
| `Ctrl+K` | Search conversations |
| `Escape` | Cancel / close dialog |

## Agent

| Shortcut | Action |
|---|---|
| `Ctrl+Shift+K` | Kill switch (emergency stop) |
| `Ctrl+Shift+B` | Toggle bypass mode |

## Window

| Shortcut | Action |
|---|---|
| `Ctrl+M` | Minimize to tray |
| `Ctrl+Q` | Quit |
| `Ctrl+,` | Settings |
| `F11` | Fullscreen |

On macOS, replace `Ctrl` with `Cmd` (global shortcuts unchanged). Global shortcuts customizable in **Settings** → **Shortcuts**.
