# Keyboard Shortcuts

## Global Shortcuts

These work even when Aegis AI is not the focused window:

| Shortcut | Action |
|---|---|
| `Ctrl+Alt+V` | Push-to-talk (hold to record voice input) |
| `Ctrl+Alt+A` | Show/hide Aegis AI window |

## Application Shortcuts

These work when the Aegis AI window is focused:

### Navigation

| Shortcut | Action |
|---|---|
| `Ctrl+1` | Switch to Chat view |
| `Ctrl+2` | Switch to Providers view |
| `Ctrl+3` | Switch to Memory view |
| `Ctrl+4` | Switch to Security view |
| `Ctrl+5` | Switch to Modes view |
| `Ctrl+6` | Switch to Settings view |
| `Ctrl+7` | Switch to Web view |

### Chat

| Shortcut | Action |
|---|---|
| `Enter` | Send message |
| `Shift+Enter` | New line in input |
| `Ctrl+N` | New conversation |
| `Ctrl+K` | Search conversations |
| `Escape` | Cancel streaming response / close dialog |

### Agent

| Shortcut | Action |
|---|---|
| `Ctrl+Shift+K` | Trip kill switch (emergency stop) |
| `Ctrl+Shift+B` | Toggle bypass mode |

### Window

| Shortcut | Action |
|---|---|
| `Ctrl+M` | Minimize to tray |
| `Ctrl+Q` | Quit application |
| `Ctrl+,` | Open Settings |
| `F11` | Toggle fullscreen |

### Editing

| Shortcut | Action |
|---|---|
| `Ctrl+C` | Copy selected text |
| `Ctrl+V` | Paste from clipboard |
| `Ctrl+A` | Select all text |

## macOS Shortcuts

On macOS, replace `Ctrl` with `Cmd` for most shortcuts. The global
shortcuts (`Ctrl+Alt+V`, `Ctrl+Alt+A`) remain the same.

## Customizing Shortcuts

Global shortcuts can be customized in **Settings** → **Shortcuts**.
Application shortcuts are fixed and cannot be changed.

## Shortcut Conflicts

If a global shortcut conflicts with another application:

1. Close the conflicting application, or
2. Change the Aegis AI shortcut in Settings.

Common conflicts:

- `Ctrl+Alt+V` may conflict with video conferencing mute shortcuts.
- `Ctrl+Alt+A` may conflict with accessibility tools.
