# Chat

The primary interface for interacting with AI providers.

## Starting a Conversation

1. Click **Chat** in sidebar (or `Ctrl+1`)
2. Type your message → **Enter** to send (**Shift+Enter** for new line)
3. AI response streams in real time

## Managing Conversations

- **New** — `Ctrl+N` or **+** button
- **Switch** — click in sidebar list
- **Search** — sidebar search bar
- **Delete** — right-click → Delete (permanent)

## Message Actions

Right-click any message: **Copy**, **Regenerate** (assistant), **Edit** (user).

## Canceling

Click the **Stop** button during streaming to cancel. Also works for agent loops.

## System Prompt

Set a custom system prompt in Settings. Prepended to every conversation.

## Markdown Rendering

AI responses render as Markdown: code blocks with syntax highlighting, tables, links, LaTeX math (KaTeX).

## Token Usage

Chat input shows estimated token count. After response, total tokens (prompt + completion) displayed below the bubble.
