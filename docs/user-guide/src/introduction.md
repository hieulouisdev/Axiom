# Introduction

**Aegis AI** — a secure, cross-platform AI assistant with computer-use, persistent memory, and built-in auto-defense.

## Key Features

- **90+ AI providers** — switch instantly between cloud and local providers
- **Computer-use agent** — 28 tools gated by a 5-level safety policy
- **Security monitoring** — process monitor, file scanner, network anomaly detector, auto-defense
- **Memory & RAG** — persistent conversations, knowledge base with vector search
- **Voice I/O** — push-to-talk, cloud Whisper STT, OS-native/ElevenLabs TTS
- **Privacy first** — zero telemetry, API keys in OS keychain, data stays on your machine

## Installation

Download from [releases](https://github.com/hieulouisdev/Axiom/releases):

| Platform | File |
|---|---|
| Linux (x86_64) | `.AppImage` or `.deb` |
| Windows | `.exe` or `.msi` |

## First Launch

1. Start Aegis AI → Chat view opens
2. Open **Settings** → configure your first AI provider + API key
3. Start chatting!
